# 灵动岛音乐播放器 · Dynamic Island Player

一个**单文件、双击就能用**的网页应用：`index.html`。播放音乐时会同步到顶部的 iPhone「灵动岛」UI。

## 打开方式

直接用浏览器打开 `dynamic-island/index.html` 即可，无需安装、无需联网、零依赖。

📱 用手机浏览器打开、把页面顶到屏幕最上方，最像真机灵动岛。

## 真能用的功能

- **音乐播放**：内置三首合成旋律（纯 Web Audio 生成，断网也响）。播放 / 暂停 / 上一首 / 下一首 / 音量都是真实生效的。
- **进度条**：实时跟随播放，可点击或拖动跳转。
- **导入我的音乐**：点「＋ 添加我的音乐」选本地音频文件（mp3/m4a…），真实播放，灵动岛显示歌名。
- **灵动岛联动**：只有真正在播放时律动条才跳；点灵动岛本体可在紧凑 / 展开态之间切换，展开态里的播放控制真实可用。

## 模拟演示的功能

- **来电**：点「📞 模拟来电」会真的响铃（Web Audio 生成铃声）、接通后真的开始计通话时长、挂断真的结束并可恢复音乐。这是**模拟**——网页无法接入真实电话。

## 做不到的事（老实说）

网页里的单个 HTML 文件**无法**：读取你的 Spotify / Apple Music「正在播放」、接听手机真实来电、常驻在系统状态栏。这些需要系统权限或账号授权。想在真机顶部常驻灵动岛效果，iOS 是系统自带、安卓可用 dynamicSpot 之类的 App。
