# 灵动岛 Dynamic Island Demo

纯前端（HTML / CSS / JS，零依赖）实现的 iPhone「灵动岛」动效模拟。

## 打开方式

直接用浏览器打开 `index.html` 即可，无需安装任何东西：

```bash
# 方式一：双击 index.html

# 方式二：本地起个静态服务（手机同局域网也能访问）
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000/dynamic-island/
```

📱 用手机浏览器打开、把页面顶到屏幕最上方，效果最接近真机。

## 有哪些状态

点击顶部的小黑条，或点下方的场景卡片切换：

| 场景 | 说明 |
| --- | --- |
| 🎵 音乐播放 | 紧凑态显示歌名 + 律动条，点岛可展开成播放控制面板 |
| 📞 来电 | 显示来电人与接听/挂断，点岛展开成大按钮 |
| ⏱ 计时器 | 实时倒计时 |
| ⚡️ 充电 | 电量提示 |
| 🔒 Face ID | 解锁脉冲动画 |
| ⚫️ 收起 | 回到默认摄像头小点 |

## 说明

这是网页模拟效果，**并非真机灵动岛**。真正的 iPhone 灵动岛是 iOS 系统能力，第三方无法作为「插件」安装；安卓上可用 dynamicSpot 等 App 获得类似体验。
